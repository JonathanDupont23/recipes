# J's Recipe Box

A simple recipe site: recipes in grams, sorted by dish type and protein, with versions and bake logs.

- `index.html` is the page.
- `recipes.json` holds every recipe. Add or change recipes there.
- `manifest.json`, `sw.js` and the icons let it be added to a phone's home screen and work offline.

Hosted with GitHub Pages from the `main` branch.
